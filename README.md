# Discord-Giveaway Bot

Бот для проведения и администрирования розыгрышей в Discord, написанный на Python 3.12+ с использованием библиотеки Disnake 2.12+. Построен на интерактивных компонентах нового поколения (`disnake.ui.Container`, `Section`, `ActionRow`), модальных окнах и контекстных командах.

## Стек технологий

- Python 3.12+
- Disnake 2.12+ (поддержка `ui.Container`, `ui.Section`, `FileUpload`)
- SQLite + `aiosqlite` (асинхронное локальное хранение данных)

## Возможности

- **Интерактивный конструктор розыгрышей**: создание и настройка заголовка, описания, призовых мест, времени и баннера через модальные окна без спама в чат.
- **Шаблоны розыгрышей**: сохранение пресетов условий и быстрое создание повторяющихся розыгрышей в один клик.
- **Гибкие условия участия**:
  - Голосовой канал (Voice): участники могут свободно перемещаться между любыми голосовыми комнатами сервера, время и баллы накапливаются непрерывно.
  - Трибуна (Stage): время засчитывается строго при нахождении на трибуне. При переходе в обычный войс подсчет времени приостанавливается.
  - Начисление баллов: 0.1 балла за минуту в войсе/трибуне с формулой сглаживания шансов (защита от монополизации вероятности).
  - Обязательное нахождение на сервере-партнере с проверкой членства.
- **Административная панель (Apps -> Управление)**:
  - Вызывается через контекстное меню сообщения розыгрыша (ПКМ по сообщению).
  - Статус, количество участников и уникальных пользователей, таймер завершения.
  - Досрочное завершение розыгрыша с подтверждением.
  - Проведение реролла (повторного выбора победителей).
  - Список участников: пагинация по участникам, победители автоматически закрепляются на первой странице сверху с отметкой 👑 для быстрой проверки модераторами.
  - Карточка участника с возможностью исключения (kick) из розыгрыша.

## Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/Crone720/Discord-Giveaway.git
cd Discord-Giveaway
```

2. Создайте и активируйте виртуальное окружение:
```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux / macOS:
source .venv/bin/activate
```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```

4. Создайте файл `.env` на основе примера:
```bash
cp .env.example .env
```
Заполните параметры в `.env`:
```env
BOT_TOKEN=ваш_токен_бота
TEST_GUILD_ID=id_вашего_сервера_для_быстрой_регистрации_команд
```

5. Запустите бота:
```bash
python -m bot.main
```
